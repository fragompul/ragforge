# RagForge

A dependency-free retrieval-augmented generation toolkit: hybrid BM25 + vector search, HNSW with
in-graph filtering, guardrails, verifiable citations, multi-hop agents and an MCP server.

* **[Live demo](https://fragompul.github.io/ragforge/)** — the whole library running in your browser (Pyodide).
* **[Guides](guides.md)** — task-oriented how-tos.
* **[Evaluation](evaluation.md)** — measured results on public datasets, including where features do *not* help.

```bash
pip install ragforge
ragforge demo
```
